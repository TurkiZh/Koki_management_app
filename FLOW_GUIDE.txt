================================================================================
   KOKI MANAGEMENT APP — LEARNING PATH & IMPLEMENTATION GUIDE
================================================================================

PROJECT CONTEXT:
  A management app for a small sweet factory owner who sells products to coffee
  shops. Features: account creation for coffee shop owners, order placement,
  order tracking, and admin management. Will integrate with AWS later.

CURRENT STATE:
  - app.ts           → bare root component with just a title
  - app.html         → just shows <h1>Koki Management App</h1>
  - app.css          → empty
  - app.routes.ts    → empty routes array
  - app.config.ts    → has provideRouter already set up (don't touch this yet)
  - components/      → empty (you will create everything)
  - services/        → deleted (you will create everything)

HOW TO USE THIS GUIDE:
  After finishing each course lesson, come here and do the corresponding step.
  Each step tells you WHAT to build, not HOW — that's what the course teaches.
  Build it yourself. If you get stuck, ask me to review what you've done.

================================================================================
STEP 1 — COMPONENTS
================================================================================
What you learned: How to create components, use selectors, templates, styles.

What to build:
  1. Create a LoginComponent         → src/app/components/login/
  2. Create a SidebarComponent       → src/app/components/sidebar/
  3. Create a DashboardComponent     → src/app/components/dashboard/
  4. Create a NewOrderComponent      → src/app/components/new-order/
  5. Create a OrderHistoryComponent  → src/app/components/order-history/
  6. Create a CurrentOrderComponent  → src/app/components/current-order/

  Use the Angular CLI to generate them:
    ng generate component components/login
    ng generate component components/sidebar
    ng generate component components/dashboard
    ng generate component components/new-order
    ng generate component components/order-history
    ng generate component components/current-order

  For now, each component just needs a simple HTML template with a heading
  that says what it is (e.g. <h2>Login</h2>). You'll fill them in later.

  Update app.html to show at least one component to verify it works.
  (Import it in app.ts and use its selector in app.html)

STEP 2 — DATA BINDING
================================================================================
What you learned: Interpolation {{ }}, property binding [ ], event binding ( ),
                  two-way binding [( )].

What to build:
  1. LoginComponent:
     - Add username and password fields
     - Use two-way binding [(ngModel)] on the input fields
       (you'll need to import FormsModule)
     - Use event binding (click) on a "Login" button
     - Use interpolation {{ }} to show a welcome message or error message
     - Use property binding [disabled] to disable the button when fields are empty

  2. NewOrderComponent:
     - Add a product list with hardcoded product names and prices
     - Use property binding [disabled] on "Order" buttons for unavailable products
     - Use event binding (click) to add products to an order array
     - Use interpolation to show the current order total

================================================================================
STEP 3 — SIGNALS
================================================================================
What you learned: signal(), computed(), effect().

What to build:
  1. Go back to app.ts:
     - Convert the title property to a signal: title = signal('Koki Management App')
     - Update app.html to use title() instead of title

  2. LoginComponent:
     - Convert username, password, errorMessage to signals
     - Create a computed signal for whether the form is valid (both fields filled)
     - Bind the button's [disabled] to the computed signal

  3. NewOrderComponent:
     - Convert the order items array to a signal
     - Create a computed signal for total price
     - Use effect() to log whenever the order changes (for debugging)

  4. CurrentOrderComponent:
     - Create signals for: orderItems, orderTime, canCancel
     - Use computed() to calculate total
     - Use hardcoded data for now

================================================================================
STEP 4 — CONTROL FLOW STATEMENTS
================================================================================
What you learned: @if, @else, @for, @switch, @empty.

What to build:
  1. LoginComponent:
     - Use @if to show error message only when it exists
     - Use @if/@else to toggle between login form and "logged in" state

  2. SidebarComponent:
     - Create a hardcoded menu items array with: name, icon, requiredRole
     - Use @for to loop through and display menu items
     - Use @if to conditionally show admin-only items (hardcode isAdmin for now)

  3. NewOrderComponent:
     - Use @for to loop through products and display them
     - Use @if to show "available" vs "unavailable" styling
     - Use @empty inside @for to show "No products available" when list is empty

  4. OrderHistoryComponent:
     - Use @for to loop through a hardcoded list of past orders
     - Use @if to show "No orders yet" when list is empty
     - Use @switch on order status to show different badges (pending/completed/cancelled)

  5. CurrentOrderComponent:
     - Use @if to show order details or "No active order" message
     - Use @for to list ordered items

STEP 5 — ROUTING
================================================================================
What you learned: RouterModule, routerLink, router-outlet, route params, child routes.

What to build:
  1. Set up routes in app.routes.ts:
     - '/login'     → LoginComponent
     - ''           → redirects to '/dashboard'
     - '/dashboard' → DashboardComponent (with child routes below)
     - '**'         → redirects to '/login'

  2. Update app.html:
     - Replace the <h1> with <router-outlet></router-outlet>
     - Import RouterOutlet in app.ts

  3. Create a MainLayoutComponent (src/app/components/main-layout/):
     - This wraps the sidebar + content area
     - Has its own <router-outlet> for child pages
     - Route '' uses MainLayoutComponent with children:
         '/dashboard'      → DashboardComponent
         '/new-order'      → NewOrderComponent
         '/order-history'  → OrderHistoryComponent
         '/current-order'  → CurrentOrderComponent

  4. SidebarComponent:
     - Add [routerLink] to each menu item
     - Add routerLinkActive to highlight the active page

  5. LoginComponent:
     - After successful login, use Router.navigate(['/dashboard'])

STEP 18 — INTERCEPTOR
================================================================================
What you learned: HttpInterceptorFn, request/response interception.

What to build:
  1. Create an AuthInterceptor (src/app/interceptors/auth.interceptor.ts):
     - Attach the JWT token to every outgoing request's Authorization header
     - Format: Authorization: Bearer <token>
     - Register it in app.config.ts with withInterceptors([authInterceptor])

  2. Create a LoadingInterceptor:
     - Set a global loading signal to true when a request starts
     - Set it to false when the request completes
     - Use this to show/hide a global loading bar

  3. Create an ErrorInterceptor:
     - Catch HTTP errors globally
     - If 401 → redirect to login (token expired)
     - If 500 → show a notification via NotificationService
     - Log errors for debugging

STEP 19 — canActivate GUARD
================================================================================
What you learned: Route guards, canActivate, functional guards.

What to build:
  1. Create an AuthGuard (src/app/guards/auth.guard.ts):
     - Functional guard (not class-based)
     - Check if user is logged in via AuthService
     - If not → redirect to /login
     - Apply to all routes except /login

  2. Create an AdminGuard (src/app/guards/admin.guard.ts):
     - Check if user has 'admin' role
     - If not → redirect to /dashboard
     - Apply to admin-only routes: /admin/new-account, etc.

  3. Update app.routes.ts:
     - Add canActivate: [authGuard] to the main layout route
     - Add canActivate: [adminGuard] to admin routes

  4. Add a route for /admin/new-account with the admin guard

BONUS — THINGS YOUR COURSE MIGHT NOT COVER BUT ARE IMPORTANT
================================================================================

  A. ENVIRONMENT CONFIGURATION
     - Use environment.ts and environment.prod.ts for API URLs
     - Switch between local mock and AWS endpoints easily

  B. LAZY LOADING
     - Use loadComponent in routes (you already saw this in routing)
     - Each component loads only when its route is visited
     - This keeps the app fast as it grows

  C. ERROR HANDLING
     - Create a global error handler
     - Gracefully handle network failures
     - Show user-friendly messages instead of blank screens

  D. MODELS/INTERFACES
     - Create TypeScript interfaces for your data:
       src/app/models/user.model.ts
       src/app/models/order.model.ts
       src/app/models/product.model.ts
     - Use these everywhere instead of 'any'

  E. RESPONSIVE DESIGN
     - Make the sidebar collapsible on mobile
     - Use CSS media queries for different screen sizes
     - Test on different viewport sizes
